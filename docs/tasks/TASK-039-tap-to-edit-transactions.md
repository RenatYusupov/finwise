## 📋 ТЗ (заполняет PM)

### Проблема

В списке транзакций ([`TransactionsPage`](apps/web/src/pages/transactions/TransactionsPage.tsx)) каждая строка реализована через [`SwipeableRow`](apps/web/src/pages/transactions/TransactionsPage.tsx:307) — свайп влево открывает панель с кнопками «Изменить» и «Удалить». Это паттерн iOS, но он **плохо работает в Telegram WebView**:

1. Свайп конфликтует со скроллом страницы — пользователь часто случайно скроллит вместо свайпа
2. Кнопки не видны по умолчанию — пользователь не знает, что они есть
3. Паттерн нестандартен для Android-пользователей (большинство аудитории Telegram в России)

**Правильный паттерн для TMA:** нажал на транзакцию → открылся bottom sheet с деталями + кнопками «Редактировать» и «Удалить» внутри.

### Решение

1. **Убрать `SwipeableRow`** — заменить на обычный `div` с `onClick`
2. **Нажатие на транзакцию** → открывает `EditTransactionSheet` (уже существует)
3. **Кнопка «Удалить»** переносится внутрь `EditTransactionSheet` — в нижнюю часть, красная, с подтверждением
4. **Свайп-логика удаляется полностью** — `handleTouchStart`, `handleTouchMove`, `handleTouchEnd`, `confirmDelete`, `swipeX` state

**Визуальный результат строки транзакции:**
```
┌─────────────────────────────────────────────────────┐
│ 🍔  Кафе Пушкин              −2 400 ₽               │
│     15 мая                                          │
└─────────────────────────────────────────────────────┘
         ↑ нажатие → открывает EditTransactionSheet
```

**EditTransactionSheet после изменения:**
```
┌─────────────────────────────────────────────────────┐
│  Редактировать операцию                    ✕        │
│  ─────────────────────────────────────────────────  │
│  Сумма: [2 400]                                     │
│  Категория: [Кафе ▾]                                │
│  Описание: [Кафе Пушкин]                            │
│  Дата: [15.05.2025]                                 │
│  ─────────────────────────────────────────────────  │
│  [        Сохранить        ]                        │
│  [        Удалить          ]  ← красная, внизу      │
└─────────────────────────────────────────────────────┘
```

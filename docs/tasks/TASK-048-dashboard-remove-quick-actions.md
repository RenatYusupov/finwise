## 📋 ТЗ (заполняет PM)

### Проблема

CJM аудит выявил: весь блок «быстрых действий» на Dashboard дублирует существующие элементы навигации без добавочной ценности.

| Кнопка | Дубль |
|---|---|
| ↓ «Добавить расход» | `AddTransactionFab` (фиксированная кнопка + bottom right) |
| ↑ «Добавить доход» | `AddTransactionFab` (с параметром type=income) |
| 📊 «Анализ» | BottomNav → Анализ |
| 🤖 «AI» | BottomNav → AI (центральная кнопка) |

Кроме этого иконка 👤 в хедере дублирует BottomNav → Профиль.

Блок занимает ~110px вертикального пространства. Dashboard должен быть лентой персональных данных, не навигационным хабом.

### Решение

**MVP: удалить дублирующие элементы:**

- Удалить весь блок «Quick actions» (primary CTA «Добавить расход» + строка из 3 кнопок «Доход / Анализ / AI»)
- Убрать иконку 👤 из хедера (Профиль есть в BottomNav)
- Контекстную ссылку «Анализ →» в компактной карточке месяца — **оставить** (она в контексте чисел, не навигационная)

**Out of scope:**
- Изменение FAB (`AddTransactionFab`)
- Изменение BottomNav
- Добавление новых элементов на Dashboard

### Затрагиваемые файлы

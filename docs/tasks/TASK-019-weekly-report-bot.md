## 📋 ТЗ (Product Manager)

### Проблема пользователя

Пользователь не получает регулярного обзора своих финансов. Без еженедельного напоминания он забывает проверять приложение и теряет контроль над бюджетом. Еженедельный отчёт в Telegram — это «точка возврата» в приложение.

### User Story

> Как пользователь, я хочу получать еженедельный финансовый отчёт в Telegram каждое воскресенье, чтобы видеть итоги недели и возвращаться в приложение для детального анализа.

### Функциональные требования

1. **Cron job** в notification-service: каждое воскресенье в 18:00 UTC
2. **Содержание отчёта:**
   - Заголовок: «📊 Финансовый отчёт за неделю [дата–дата]»
   - Расходы за неделю: общая сумма
   - Топ-3 категории расходов с суммами
   - Сравнение с прошлой неделей: «+12% vs прошлая неделя» или «-8%»
   - SafeToSpend на оставшиеся дни месяца
   - AI-комментарий: 1–2 предложения с персонализированным наблюдением
   - CTA-кнопка: «📱 Открыть FinWise» (deep link в Mini App)
3. **Форматирование** — Telegram Markdown:
   ```
   📊 *Финансовый отчёт* 12–18 мая
   
   💸 Расходы за неделю: *8 450 ₽* (+12% vs прошлая)
   
   Топ категории:
   🍕 Кафе — 2 800 ₽
   🛒 Продукты — 2 100 ₽
   🚇 Транспорт — 1 200 ₽
   
   💰 SafeToSpend: *1 850 ₽/день* (осталось 13 дней)
   
   💡 На этой неделе вы потратили на кафе на 40% больше обычного.
   
   [📱 Открыть FinWise](https://t.me/finwise_bot/app)
   ```
4. **Отправка только пользователям** с включёнными еженедельными отчётами (настройка из TASK-020)
5. **Пропуск недели** если у пользователя 0 транзакций за неделю — не отправлять пустой отчёт
6. **AI-комментарий** генерируется через ai-service (POST /ai/weekly-summary)

### Файлы для изменения

- `services/notification-service/src/index.ts` — добавить cron job для еженедельного отчёта
- `services/ai-service/src/index.ts` — добавить POST /ai/weekly-summary
- `apps/web/src/pages/profile/ProfilePage.tsx` — добавить настройку «Еженедельный отчёт» (TASK-020)

### Acceptance Criteria

**AC-1:** Given воскресенье 18:00 UTC, When cron срабатывает, Then все пользователи с включёнными отчётами получают сообщение в Telegram

**AC-2:** Given отчёт отправлен, When пользователь его читает, Then содержит: расходы за неделю, топ-3 категории, SafeToSpend, AI-комментарий

**AC-3:** Given пользователь с 0 транзакциями за неделю, When cron срабатывает, Then отчёт НЕ отправляется

**AC-4:** Given сравнение с прошлой неделей, When расходы выросли, Then показывается «+X%» красным (Telegram emoji 🔴 или текст)

**AC-5:** Given AI-комментарий, When отчёт отправлен, Then комментарий персонализирован (упоминает конкретную категорию или паттерн пользователя)

**AC-6:** Given CTA-кнопка «Открыть FinWise», When нажата в Telegram, Then открывается Mini App

**AC-7:** Given пользователь отключил еженедельные отчёты (TASK-020), When cron срабатывает, Then отчёт НЕ отправляется

**AC-8:** Given ai-service недоступен при генерации отчёта, When cron срабатывает, Then отчёт отправляется без AI-комментария (fallback на шаблонный текст)

### Edge Cases

- **Первая неделя пользователя (< 7 дней данных):** отчёт отправляется без сравнения с прошлой неделей
- **Пользователь заблокировал бота:** Telegram вернёт 403, пользователь помечается как «бот заблокирован», отчёты прекращаются
- **Очень много пользователей (>1000):** отправка батчами по 30 сообщений/секунду (лимит Telegram Bot API)
- **Часовой пояс:** отчёт отправляется в 18:00 UTC (21:00 МСК) — ASSUMPTION нужна валидация

### Метрики успеха

- **Primary:** % пользователей, открывших приложение в течение 24 часов после получения отчёта ≥ 30% (retention trigger)
- **Guardrail:** % пользователей, отписавшихся от отчётов после первого получения ≤ 10%

### Явно вне скоупа

- Настройка дня и времени отправки отчёта пользователем
- Ежедневные отчёты
- Отчёт в формате PDF или изображения
- Интерактивные кнопки в отчёте (Telegram inline keyboard)

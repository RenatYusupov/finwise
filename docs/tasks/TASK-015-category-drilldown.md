## 📋 ТЗ (Product Manager)

### Проблема пользователя

На AnalyticsPage пользователь видит что потратил 8 200 ₽ на «Продукты», но не может понять из каких конкретно транзакций складывается эта сумма. Нет возможности провалиться в детали категории.

### User Story

> Как пользователь, я хочу нажать на категорию в аналитике и увидеть все транзакции этой категории за выбранный период, чтобы понять из чего складываются мои расходы.

### Функциональные требования

1. **Тап на категорию** в AnalyticsPage (в pie chart или в списке категорий) → открывает экран детализации
2. **Экран детализации категории** (`/analytics/category/:categoryId`):
   - Заголовок: иконка + название категории
   - Итоговая сумма за период: «Итого: 8 200 ₽»
   - Среднее за месяц (если период > 1 месяца): «В среднем: 7 800 ₽/мес»
   - Список всех транзакций категории за выбранный период (хронологически, новые сверху)
   - Мини bar chart: расходы по неделям внутри периода
3. **Период** наследуется из AnalyticsPage (тот же period selector)
4. **Тап на транзакцию** в списке → открывает форму редактирования (TASK-004)
5. **Кнопка «Назад»** возвращает на AnalyticsPage с сохранённым периодом

### Acceptance Criteria

**AC-1:** Given тап на категорию «Кафе» в AnalyticsPage, When переход выполнен, Then открывается экран с заголовком «Кафе» и списком транзакций этой категории за текущий период

**AC-2:** Given экран детализации, When отображается, Then показывается итоговая сумма всех транзакций категории за период

**AC-3:** Given период «3 месяца» выбран в AnalyticsPage, When открыта детализация, Then список содержит транзакции за последние 3 месяца

**AC-4:** Given тап на транзакцию в списке детализации, When переход выполнен, Then открывается форма редактирования транзакции (TASK-004)

**AC-5:** Given кнопка «Назад», When нажата, Then возврат на AnalyticsPage с тем же выбранным периодом

**AC-6:** Given нет транзакций в категории за период, When экран открыт, Then показывается «Нет транзакций в этой категории за выбранный период»

**AC-7:** Given период > 1 месяца, When экран открыт, Then отображается строка «В среднем: X ₽/мес»

**AC-8:** Given мини bar chart, When экран открыт, Then отображаются столбцы по неделям с суммами расходов

### Edge Cases

- **Категория «Доходы»:** показывает доходные транзакции (не расходы)
- **Очень много транзакций (>100):** виртуализированный список или пагинация по 50
- **Одна транзакция в категории:** bar chart не отображается (нет смысла)
- **Переход с несуществующим categoryId:** редирект на AnalyticsPage

### Метрики успеха

- **Primary:** % пользователей, использующих drill-down хотя бы раз в неделю ≥ 15%
- **Guardrail:** время открытия экрана детализации < 150ms

### Явно вне скоупа

- Изменение категории транзакции прямо из drill-down (только через форму редактирования)
- Экспорт транзакций категории
- Сравнение двух категорий

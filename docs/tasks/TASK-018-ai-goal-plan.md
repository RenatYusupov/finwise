## 📋 ТЗ (Product Manager)

### Проблема пользователя

Пользователь создаёт цель «Накопить на MacBook: 150 000 ₽», но не знает:
- Реалистична ли цель при текущих доходах и расходах?
- Сколько нужно откладывать каждый месяц?
- Какие категории расходов можно сократить для ускорения накопления?

### User Story

> Как пользователь, я хочу получить AI-план достижения финансовой цели с конкретными шагами и рекомендациями по экономии, чтобы понять как реально достичь цели.

### Функциональные требования

1. **Кнопка «✨ Составить план»** на GoalDetailPage — запускает генерацию плана
2. **AI-план** генерируется на основе:
   - Целевая сумма и текущий прогресс
   - Дедлайн (если установлен)
   - Медианный доход пользователя за 3 месяца
   - Медианные расходы по категориям за 3 месяца
   - SafeToSpend текущего месяца
3. **Содержание плана:**
   - **Ежемесячный взнос:** «Нужно откладывать X ₽/месяц»
   - **Срок достижения:** «При текущем темпе: [дата]» или «Цель достижима к [дедлайн]»
   - **Рекомендации по экономии:** топ-3 категории где можно сократить расходы
   - **Прогноз:** «Если сократить расходы на кафе на 30%, цель достигнете на 2 месяца раньше»
4. **Отображение плана** на GoalDetailPage под прогресс-баром:
   - Карточка с планом (сворачивается/разворачивается)
   - Кнопка «Обновить план» (пересчитать)
5. **Кнопка «Установить напоминание»** — создаёт ежемесячное напоминание через notification-service

### Acceptance Criteria

**AC-1:** Given цель с targetAmount=150000 и currentAmount=30000, When нажата «✨ Составить план», Then через ≤5 секунд отображается план с ежемесячным взносом

**AC-2:** Given план сгенерирован, When отображается, Then показывается ежемесячный взнос, дата достижения и минимум 1 рекомендация по экономии

**AC-3:** Given дедлайн установлен и цель недостижима к дедлайну, When план отображается, Then показывается предупреждение «При текущем темпе цель не будет достигнута к [дедлайн]. Нужно откладывать X ₽/мес»

**AC-4:** Given рекомендация «сократить расходы на кафе», When отображается, Then показывается текущая сумма расходов, предлагаемое сокращение и влияние на срок

**AC-5:** Given кнопка «Обновить план», When нажата, Then план пересчитывается с актуальными данными

**AC-6:** Given пользователь с < 1 месяца данных, When нажата «✨ Составить план», Then показывается «Недостаточно данных для составления плана. Добавьте транзакции за хотя бы 1 месяц»

**AC-7:** Given кнопка «Установить напоминание», When нажата, Then создаётся ежемесячное напоминание «Пополни цель [название]: X ₽»

**AC-8:** Given ai-service недоступен, When нажата «✨ Составить план», Then показывается ошибка «Не удалось составить план. Попробуйте позже»

### Edge Cases

- **Цель без дедлайна:** план без оценки «достижимо к дедлайну», только «при текущем темпе»
- **Цель уже достигнута (currentAmount >= targetAmount):** кнопка «Составить план» не отображается
- **Нулевой доход:** план не генерируется, показывается «Добавьте доходы для составления плана»
- **Очень маленькая цель (< 1000 ₽):** план генерируется, но без рекомендаций по экономии

### Метрики успеха

- **Primary:** % пользователей с целями, использующих AI-план ≥ 20%
- **Guardrail:** % пользователей, установивших ежемесячное напоминание после просмотра плана ≥ 15%

### Явно вне скоупа

- Автоматическое пополнение цели
- Интеграция с банковскими накопительными счетами
- Несколько сценариев плана («агрессивный», «умеренный», «мягкий»)

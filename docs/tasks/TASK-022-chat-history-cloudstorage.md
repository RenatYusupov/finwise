## 📋 ТЗ (Product Manager)

### Проблема пользователя

История AI-чата не сохраняется между сессиями. При закрытии и повторном открытии приложения весь контекст разговора теряется. Пользователь не может вернуться к предыдущим советам AI или продолжить разговор.

### User Story

> Как пользователь, я хочу чтобы история моего AI-чата сохранялась между сессиями, чтобы я мог вернуться к предыдущим советам и продолжить разговор с контекстом.

### Функциональные требования

1. **Персистентность истории чата** — сообщения AI-чата сохраняются в Telegram CloudStorage
2. **Лимит хранения:** последние 50 сообщений (25 пар user/assistant)
3. **Структура хранения:** `AiMessage[]` сериализуется в JSON, разбивается на чанки по 3500 символов (аналогично существующему механизму в store.ts)
4. **Ключи CloudStorage:** `finwise_chat_0`, `finwise_chat_1`, ... (отдельно от основных данных)
5. **Загрузка при старте:** при открытии AiChatPage загружается история из CloudStorage
6. **Автосохранение:** после каждого нового сообщения история сохраняется (debounce 2 секунды)
7. **Кнопка «Очистить историю»** в AiChatPage — удаляет все сообщения из store и CloudStorage
8. **Индикатор загрузки** при первом открытии чата пока история загружается

### Acceptance Criteria

**AC-1:** Given пользователь написал 5 сообщений в AI-чат, When закрывает и открывает приложение, Then история чата восстановлена — все 5 сообщений видны

**AC-2:** Given история чата > 50 сообщений, When новое сообщение добавлено, Then самое старое сообщение удаляется (FIFO, лимит 50)

**AC-3:** Given AiChatPage открывается впервые после перезапуска, When история загружается, Then показывается spinner «Загрузка истории...» до завершения загрузки

**AC-4:** Given кнопка «Очистить историю», When нажата и подтверждена, Then все сообщения удаляются из store и CloudStorage, чат показывает пустое состояние

**AC-5:** Given история чата сохранена, When CloudStorage недоступен при загрузке, Then чат открывается с пустой историей (не показывает ошибку пользователю)

**AC-6:** Given автосохранение, When пользователь отправил сообщение, Then через 2 секунды история сохранена в CloudStorage (debounce)

**AC-7:** Given история из 50 сообщений в CloudStorage, When загружается, Then все 50 сообщений корректно десериализованы и отображены в правильном порядке

**AC-8:** Given очень длинное сообщение AI (>3500 символов), When сохраняется, Then корректно разбивается на чанки и восстанавливается без потерь

### Edge Cases

- **CloudStorage заполнен:** при ошибке записи — логировать, не показывать ошибку пользователю
- **Повреждённые данные в CloudStorage:** при ошибке парсинга — начать с пустой истории
- **Одновременное открытие на двух устройствах:** последняя запись побеждает (нет merge для чата)
- **Сообщения без timestamp:** добавить `Date.now()` при сохранении если отсутствует

### Метрики успеха

- **Primary:** % пользователей, у которых история чата восстанавливается корректно ≥ 99%
- **Guardrail:** время загрузки истории чата < 500ms

### Явно вне скоупа

- Синхронизация истории чата с бэкендом (только CloudStorage)
- Поиск по истории чата
- Экспорт истории чата
- Несколько чат-сессий / тредов

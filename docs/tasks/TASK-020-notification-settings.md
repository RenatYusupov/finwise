## 📋 ТЗ (Product Manager)

### Проблема пользователя

Пользователь получает уведомления, но не может управлять ими. Некоторые уведомления могут быть нежелательны (например, пользователь не хочет еженедельный отчёт или хочет отключить напоминания о регулярных платежах).

### User Story

> Как пользователь, я хочу управлять какие уведомления я получаю в Telegram, чтобы получать только нужные мне оповещения и не раздражаться от лишних сообщений.

### Функциональные требования

1. **Секция «Уведомления»** в ProfilePage — список переключателей:
   - «Превышение бюджета» (toggle, по умолчанию: ВКЛ)
   - «Напоминания о регулярных платежах» (toggle, по умолчанию: ВКЛ)
   - «Еженедельный отчёт» (toggle, по умолчанию: ВКЛ)
   - «Проактивные инсайты» (toggle, по умолчанию: ВКЛ)
2. **Сохранение настроек** в store (локально) и синхронизация с finance-service (поле `notificationSettings` в профиле пользователя)
3. **Немедленное применение** — при выключении уведомления notification-service перестаёт их отправлять
4. **Описание под каждым toggle** — краткое пояснение что именно отправляется
5. **«Отключить все»** — кнопка внизу секции, отключает все уведомления одним действием

### Файлы для изменения

- `apps/web/src/pages/profile/ProfilePage.tsx` — добавить секцию настроек уведомлений
- `apps/web/src/features/finance/store.ts` — добавить `notificationSettings` в state
- `services/finance-service/src/index.ts` — добавить поле `notificationSettings` в профиль пользователя
- `services/notification-service/src/index.ts` — проверять настройки перед отправкой

### Структура данных

```typescript
interface NotificationSettings {
  budgetAlerts: boolean;       // default: true
  recurringReminders: boolean; // default: true
  weeklyReport: boolean;       // default: true
  aiInsights: boolean;         // default: true
}
```

### Acceptance Criteria

**AC-1:** Given ProfilePage открыта, When пользователь прокручивает до секции «Уведомления», Then видит 4 toggle с текущими состояниями

**AC-2:** Given toggle «Превышение бюджета» выключен, When бюджет превышен, Then Telegram-уведомление НЕ отправляется (но in-app индикатор всё равно показывается)

**AC-3:** Given toggle «Еженедельный отчёт» выключен, When воскресенье 18:00 UTC, Then еженедельный отчёт НЕ отправляется этому пользователю

**AC-4:** Given изменение toggle, When пользователь переключает, Then настройка сохраняется немедленно (без кнопки «Сохранить»), показывается toast «Настройки сохранены»

**AC-5:** Given кнопка «Отключить все», When нажата, Then все 4 toggle переключаются в OFF, показывается toast «Все уведомления отключены»

**AC-6:** Given настройки сохранены, When пользователь закрывает и открывает приложение, Then настройки сохранены (не сбрасываются)

**AC-7:** Given новый пользователь (первый запуск), When открывает ProfilePage, Then все 4 toggle включены по умолчанию

**AC-8:** Given описание под toggle «Еженедельный отчёт», When отображается, Then текст: «Краткая сводка за неделю каждое воскресенье в 21:00»

### Edge Cases

- **Нет интернета при сохранении:** настройки сохраняются локально, синхронизируются при восстановлении соединения
- **Конфликт настроек (локальные vs сервер):** приоритет у более новых (по timestamp)
- **Пользователь не авторизован (нет бэкенда):** настройки хранятся только локально в store

### Метрики успеха

- **Primary:** % пользователей, изменивших хотя бы одну настройку уведомлений ≤ 20% (если больше — уведомления слишком навязчивы)
- **Guardrail:** % пользователей, отключивших ВСЕ уведомления ≤ 5%

### Явно вне скоупа

- Настройка времени отправки уведомлений
- Настройка порога для budget alerts (только 80% и 100%)
- Уведомления по email или SMS

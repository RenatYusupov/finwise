## 📋 ТЗ (заполняет PM)

### Проблема

«Регулярные» занимает слот в BottomNav, хотя это management-экран с частотой использования 1–2 раза в месяц. «Бюджет» — прямое продолжение SafeToSpend (core value) — не представлен в навигации вообще. Пользователь видит «можно потратить 1 840 ₽» → хочет понять по каким категориям → нет очевидного пути.

Текущий состав: `Главная | Анализ | AI | Регулярные | Профиль`  
Целевой состав: `Главная | Анализ | AI | Бюджет | Профиль`

### Решение

- MVP: убрать `{ path: '/recurring', label: 'Регулярные', icon: '🔁' }` из `NAV_ITEMS`
- MVP: добавить `{ path: '/budget', label: 'Бюджет', icon: '💰' }` на его место
- MVP: сохранить порядок: Главная → Анализ → AI (центр) → Бюджет → Профиль

Доступ к `/recurring` остаётся через виджет «🔁 Ближайшие платежи» на Dashboard.

**Out of scope:**
- Изменение самих экранов /budget и /recurring
- Добавление «Цели» в nav (решение принято: Анализ + Бюджет важнее)
- Персонализация навигации пользователем

### Затрагиваемые файлы

- `apps/web/src/shared/ui/BottomNav.tsx` — обновить `NAV_ITEMS`

### Acceptance Criteria

- [ ] **AC-1:** В BottomNav нет вкладки «Регулярные».
- [ ] **AC-2:** В BottomNav есть вкладка «Бюджет» (`/budget`) на 4-й позиции (между AI и Профиль).
- [ ] **AC-3:** Порядок вкладок: Главная → Анализ → AI → Бюджет → Профиль.
- [ ] **AC-4:** Переход на `/recurring` через виджет «Ближайшие платежи» на Dashboard работает.

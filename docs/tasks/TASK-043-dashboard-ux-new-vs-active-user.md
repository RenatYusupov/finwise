## 📋 ТЗ (заполняет PM)

### Проблема

Dashboard не различает UX-путь нового и активного пользователя:

- `SafeToSpendCard` возвращала `null` для пользователей без дохода — главный виджет попросту исчезал, новый пользователь видел пустой экран без понятных следующих шагов
- Большая тёмная карточка баланса (dark gradient `#1a1a2e`) дублировала данные из SafeToSpendCard и занимала ~30% экрана без добавочной ценности
- Пустой список транзакций предлагал только «+ Добавить» — не упоминал импорт выписки как основной путь к ценности
- Раздел «Цели» скрывался при `activeGoals.length === 0` — новый пользователь не знал о функции
- Стрик показывался только при `streak > 1` — первый день не мотивировал начать серию
- Редактирование транзакции требовало перехода на отдельный экран вместо sheet прямо с главной
- Быстрые действия — 4 равные колонки, «Расход» не выделен как основное действие

### Решение

Персонализировать Dashboard под два состояния пользователя.

**Для нового пользователя (0 транзакций):**
- MVP: `SafeToSpendCard` показывает онбординг-карточку с двумя CTA («Импортировать выписку» и «Добавить доход») вместо `null`
- MVP: Пустое состояние списка транзакций — импорт как первичный CTA, «+ Добавить» как вторичный
- MVP: Раздел «Цели» всегда виден, пустое состояние с CTA «Поставь первую цель»
- MVP: Стрик ≤ 1 → кнопка «🔥 Начни серию» вместо пустого места

**Для активного пользователя:**
- MVP: Компактная white-card с тремя метриками (доходы / расходы / остаток) + ссылка «Анализ →» вместо громоздкой dark balance card. Показывается только при наличии активности в месяце
- MVP: Широкая оранжевая кнопка «Добавить расход» как primary CTA + 3 вторичных действия в ряд (Доход, Анализ, AI)
- MVP: Tap по строке транзакции открывает `EditTransactionSheet` прямо с главной
- MVP: Import nudge-карточка под списком транзакций при `transactions.length < 10`
- Enhancement: Цели сортируются по дедлайну (ближайший первый), urgency-лейбл (🟡 7 дн. / 🔴 Срок прошёл)
- Enhancement: `SafeToSpendCard` кликабельна → переход на `/budget`

**Out of scope:**
- A/B тест двух вариантов дашборда
- Персонализация на основе данных бэкенда (бэкенд — заглушка)

### Что сделано

- **`DashboardPage.tsx`**: единственный изменённый файл.
  - Добавлен `editingTx` state + `AnimatePresence` для `EditTransactionSheet`
  - `activeGoals` вычисляется через `useMemo` с сортировкой по дедлайну
  - `isNewUser` флаг (`transactions.length === 0`)
  - Хедер: стрик ≤ 1 → кнопка «🔥 Начни серию»
  - Удалена dark balance card, добавлена compact month summary (white card, только при активности)
  - `SafeToSpendCard` получила `onTap={() => navigate('/budget')}`
  - Quick actions: wide primary «Добавить расход» + 3-col grid (Доход, Анализ, AI)
  - Goals: всегда рендерится, empty state с CTA
  - Цели: urgency-лейбл по дедлайну
  - Транзакции: `onClick={() => setEditingTx(tx)}` на каждой строке
  - Пустое состояние транзакций: импорт как primary CTA
  - Import nudge при `transactions.length < 10`
  - `EditTransactionSheet` + `AnimatePresence` в конце JSX

### Что НЕ сделано

- Управление порядком виджетов пользователем (drag-to-reorder) — out of scope
- A/B тест — нет инфраструктуры

### Риски и известные ограничения

- `EditTransactionSheet` импортируется из `TransactionsPage` — если компонент переедет, импорт нужно обновить
- Compact month summary скрыта при нулевой активности — пустой дашборд не показывает историю прошлых месяцев

### Тестирование

1. Открыть дашборд с чистым store (0 транзакций, 0 дохода) → вместо SafeToSpendCard — онбординг-карточка с двумя кнопками
2. Список транзакций пустой → видны кнопки «Импортировать» и «+ Добавить»
3. Раздел «Цели» виден с карточкой «Поставь первую цель»
4. Streak = 0 или 1 → в хедере кнопка «🔥 Начни серию»
5. Добавить 3 транзакции → появляется compact month summary (white card), import nudge под списком
6. Тапнуть по строке транзакции → открывается `EditTransactionSheet` без смены экрана
7. Добавить цель с дедлайном через 3 дня → в разделе целей лейбл «🟡 3 дн. осталось»

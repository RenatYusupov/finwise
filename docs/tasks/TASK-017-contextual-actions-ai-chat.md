## 📋 ТЗ (Product Manager)

### Проблема пользователя

AI-чат отвечает на вопросы, но не может выполнять действия. Пользователь спрашивает «Добавь трату 500 рублей на кофе» или «Установи бюджет на кафе 5000 рублей» — и получает только текстовый ответ, а не реальное действие в приложении.

**ASSUMPTION — нужна валидация:** пользователи хотят управлять финансами через чат, а не только получать информацию.

### User Story

> Как пользователь, я хочу чтобы AI-чат мог выполнять действия (добавить транзакцию, установить бюджет, создать цель) по моей команде, чтобы управлять финансами голосом/текстом без навигации по экранам.

### Функциональные требования

1. **Распознавание намерений** — ai-service анализирует сообщение пользователя и определяет намерение:
   - `ADD_TRANSACTION`: «добавь трату», «потратил», «купил»
   - `SET_BUDGET`: «установи бюджет», «лимит на»
   - `CREATE_GOAL`: «создай цель», «хочу накопить»
   - `SHOW_STATS`: «сколько потратил», «покажи расходы» (только информация, без действия)

2. **Action card** — если намерение распознано, AI возвращает не только текст, но и структурированный action:
   ```json
   {
     "reply": "Добавляю трату 500 ₽ на кофе. Подтвердите?",
     "action": {
       "type": "ADD_TRANSACTION",
       "payload": { "amount": 500, "category": "cafe", "description": "Кофе" }
     }
   }
   ```

3. **Карточка подтверждения** — под ответом AI отображается карточка с деталями действия и кнопками «✓ Подтвердить» и «✕ Отмена»

4. **После подтверждения** — действие выполняется в store, показывается toast «Транзакция добавлена»

5. **Редактирование перед подтверждением** — тап на поле в карточке позволяет изменить значение (например, сумму или категорию)

6. **Поддерживаемые действия:**
   - Добавить транзакцию (сумма, категория, описание, дата)
   - Установить/обновить бюджет (категория, лимит)
   - Создать цель (название, целевая сумма, дедлайн)

### Acceptance Criteria

**AC-1:** Given сообщение «потратил 500 рублей на кофе», When AI отвечает, Then под текстом ответа отображается action card с типом ADD_TRANSACTION и суммой 500

**AC-2:** Given action card с ADD_TRANSACTION, When пользователь нажимает «✓ Подтвердить», Then транзакция добавляется в store, карточка исчезает, показывается toast «Транзакция добавлена»

**AC-3:** Given action card, When пользователь нажимает «✕ Отмена», Then карточка исчезает, действие не выполняется

**AC-4:** Given action card с суммой 500, When пользователь тапает на поле суммы, Then поле становится редактируемым, пользователь может изменить значение

**AC-5:** Given сообщение «установи бюджет на кафе 5000», When AI отвечает, Then action card типа SET_BUDGET с category=cafe и limit=5000

**AC-6:** Given сообщение «сколько я потратил на еду», When AI отвечает, Then action card НЕ отображается (только информационный ответ)

**AC-7:** Given AI не смог распознать намерение с достаточной уверенностью, When отвечает, Then action card не отображается, только текстовый ответ

**AC-8:** Given action card с CREATE_GOAL, When подтверждена, Then цель создаётся в store и пользователь видит toast «Цель создана»

### Edge Cases

- **Неполные данные в action:** если AI не распознал сумму — поле суммы пустое, кнопка «Подтвердить» заблокирована
- **Несколько действий в одном сообщении:** показывается только первое распознанное действие
- **Действие уже выполнено (повторный тап):** кнопка «Подтвердить» деактивируется после первого нажатия
- **Категория не распознана:** устанавливается «other», пользователь может изменить

### Метрики успеха

- **Primary:** % сообщений в AI-чате, завершившихся подтверждённым действием ≥ 20%
- **Guardrail:** % ложных срабатываний action card (пользователь нажал «Отмена») ≤ 30%

### Явно вне скоупа

- Голосовой ввод
- Удаление транзакций через чат
- Batch-действия («добавь 5 трат»)
- Действия с регулярными платежами через чат

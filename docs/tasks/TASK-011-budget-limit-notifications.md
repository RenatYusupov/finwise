## 📋 ТЗ (Product Manager)

### Проблема пользователя

Пользователь устанавливает бюджет по категории (например, «Кафе: 5 000 ₽/месяц»), но не получает никакого сигнала когда приближается к лимиту. Он узнаёт о превышении только когда открывает приложение и видит красный индикатор на BudgetPage.

### User Story

> Как пользователь, я хочу получать уведомление в Telegram когда трачу 80% и 100% бюджета по категории, чтобы вовремя скорректировать поведение до конца месяца.

### Функциональные требования

1. **Триггер 80%:** когда сумма расходов по категории за текущий месяц достигает 80% лимита — отправить уведомление
2. **Триггер 100%:** когда сумма расходов превышает лимит — отправить уведомление
3. **Дедупликация:** каждый триггер (80% и 100%) срабатывает только один раз в месяц на категорию
4. **In-app индикатор:** на BudgetPage карточка бюджета подсвечивается жёлтым (80%) или красным (100%)
5. **In-app баннер:** при открытии приложения после превышения показывается баннер «⚠️ Превышен бюджет: Кафе» с кнопкой «Посмотреть»
6. **Telegram-уведомление** (через notification-service):
   - 80%: «⚠️ Осторожно! Вы потратили 80% бюджета на Кафе: 4 000 ₽ из 5 000 ₽. Осталось 1 000 ₽»
   - 100%: «🚨 Бюджет превышен! Кафе: потрачено 5 800 ₽ из 5 000 ₽ (+800 ₽)»

### Файлы для изменения

- `apps/web/src/pages/budget/BudgetPage.tsx` — добавить цветовые индикаторы и баннер
- `services/finance-service/src/index.ts` — добавить вызов notification-service при добавлении транзакции
- `services/notification-service/src/index.ts` — обработчик POST /notify/budget-alert (уже в TASK-009)

### Acceptance Criteria

**AC-1:** Given бюджет «Кафе: 5 000 ₽», When добавлена транзакция и сумма расходов достигла 4 000 ₽ (80%), Then пользователь получает Telegram-уведомление с текстом про 80%

**AC-2:** Given уведомление 80% уже отправлено в этом месяце, When добавлена ещё одна транзакция и сумма всё ещё 80–99%, Then повторное уведомление НЕ отправляется

**AC-3:** Given бюджет превышен (>100%), When открыта BudgetPage, Then карточка бюджета подсвечена красным, прогресс-бар показывает >100%

**AC-4:** Given бюджет на 80–99%, When открыта BudgetPage, Then карточка подсвечена жёлтым

**AC-5:** Given бюджет превышен, When пользователь открывает приложение, Then показывается in-app баннер с названием категории и кнопкой «Посмотреть»

**AC-6:** Given тап на «Посмотреть» в баннере, When переход выполнен, Then открывается BudgetPage с прокруткой к нужной категории

**AC-7:** Given пользователь отключил уведомления о бюджете (TASK-020), When бюджет превышен, Then Telegram-уведомление НЕ отправляется, но in-app индикатор всё равно показывается

**AC-8:** Given новый месяц начался, When первая транзакция добавлена, Then счётчик дедупликации сбрасывается (уведомления снова активны)

### Edge Cases

- **Нет бюджета по категории:** уведомление не отправляется
- **Бюджет = 0:** деление на ноль — не отправлять уведомление, логировать ошибку
- **Несколько категорий превышены одновременно:** одно Telegram-сообщение со списком всех превышений
- **Транзакция удалена после превышения:** уведомление уже отправлено, не отзывать

### Метрики успеха

- **Primary:** % пользователей с бюджетами, которые не превышают лимит в следующем месяце после получения уведомления ≥ 20% (поведенческое изменение)
- **Guardrail:** % ложных срабатываний (уведомление без реального превышения) = 0%

### Явно вне скоупа

- Настройка порога уведомления (только 80% и 100%, не кастомизируется)
- Прогнозирование превышения до его наступления (Sprint 3, TASK-016)
- SMS или email уведомления

## 📋 ТЗ (Product Manager)

### Проблема пользователя

Пользователь не может выгрузить свои финансовые данные из приложения. Это создаёт «vendor lock-in» и снижает доверие: пользователь боится потерять данные или хочет проанализировать их в Excel.

### User Story

> Как пользователь, я хочу экспортировать все свои транзакции в CSV или JSON, чтобы иметь резервную копию данных и анализировать их в сторонних инструментах.

### Функциональные требования

1. **Кнопка «Экспорт данных»** в ProfilePage
2. **Форматы экспорта:**
   - CSV (для Excel/Google Sheets)
   - JSON (полный backup, включая бюджеты, цели, регулярные платежи)
3. **Диапазон дат:** «Все данные» / «Этот год» / «Произвольный период»
4. **CSV-формат транзакций:**
   ```
   Дата,Сумма,Тип,Категория,Описание
   2026-05-19,1500,expense,groceries,Пятёрочка
   ```
5. **Скачивание файла** — через Telegram `sendDocument` API (файл отправляется в чат с ботом) или через браузерный download
6. **Прогресс-индикатор** при генерации большого файла (>500 транзакций)
7. **Уведомление** после успешного экспорта: «Файл отправлен в ваш чат с ботом»

### Файлы для изменения

- `apps/web/src/pages/profile/ProfilePage.tsx` — добавить кнопку и диалог экспорта
- `services/finance-service/src/index.ts` — добавить GET /export?format=csv&from=&to=
- `services/notification-service/src/index.ts` — добавить отправку файла через Telegram

### API-контракт

```
GET /export?format=csv&from=2026-01-01&to=2026-05-31
Auth: Bearer <token>
Response 200: Content-Type: text/csv
             Content-Disposition: attachment; filename="finwise-export-2026-05.csv"
             [CSV content]

GET /export?format=json
Auth: Bearer <token>
Response 200: Content-Type: application/json
             { "transactions": [...], "budgets": [...], "goals": [...], "recurringPayments": [...] }
```

### Acceptance Criteria

**AC-1:** Given кнопка «Экспорт данных» в ProfilePage, When нажата, Then открывается диалог с выбором формата (CSV/JSON) и периода

**AC-2:** Given выбран формат CSV и период «Все данные», When нажата «Экспортировать», Then файл `finwise-export-YYYY-MM.csv` отправляется в Telegram-чат пользователя с ботом

**AC-3:** Given CSV-файл, When открыт в Excel, Then содержит колонки: Дата, Сумма, Тип, Категория, Описание — с корректными данными

**AC-4:** Given выбран формат JSON, When экспорт выполнен, Then JSON содержит все 4 коллекции: transactions, budgets, goals, recurringPayments

**AC-5:** Given экспорт >500 транзакций, When генерация идёт, Then показывается spinner «Подготовка файла...»

**AC-6:** Given успешный экспорт, When файл отправлен, Then показывается toast «Файл отправлен в Telegram» и ссылка «Открыть чат»

**AC-7:** Given произвольный период с from > to, When нажата «Экспортировать», Then показывается ошибка «Дата начала должна быть раньше даты окончания»

**AC-8:** Given пользователь без данных (0 транзакций), When экспорт выполнен, Then CSV содержит только заголовок, JSON содержит пустые массивы

### Edge Cases

- **Telegram Bot недоступен:** fallback на браузерный download (blob URL)
- **Очень большой файл (>10MB):** предупреждение «Файл большой, отправка может занять время»
- **Специальные символы в описании:** корректное экранирование в CSV (кавычки)
- **Нет бэкенда (только CloudStorage):** экспорт из локального store

### Метрики успеха

- **Primary:** % пользователей, использующих экспорт хотя бы раз ≥ 10%
- **Guardrail:** % ошибок при экспорте < 2%

### Явно вне скоупа

- Импорт данных из JSON (только экспорт)
- Экспорт в PDF
- Автоматический периодический экспорт
- Экспорт аналитических отчётов (только сырые данные)

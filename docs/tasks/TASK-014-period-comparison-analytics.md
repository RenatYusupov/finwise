## 📋 ТЗ (Product Manager)

### Проблема пользователя

AnalyticsPage показывает только текущий месяц. Пользователь не может сравнить расходы с прошлым месяцем или понять тренд: «Я трачу больше или меньше, чем обычно?»

### User Story

> Как пользователь, я хочу сравнивать расходы текущего месяца с предыдущим, чтобы видеть тренд и понимать изменилось ли моё финансовое поведение.

### Функциональные требования

1. **Period selector** в верхней части AnalyticsPage — переключатель: «Этот месяц» / «Прошлый месяц» / «3 месяца» / «6 месяцев»
2. **Режим сравнения** — toggle «Сравнить с предыдущим периодом» (включается отдельно)
3. **При включённом сравнении:**
   - Общие расходы: текущий период vs предыдущий, дельта в % и ₽ («+1 200 ₽ (+8%)»)
   - По категориям: таблица с колонками «Категория», «Текущий», «Предыдущий», «Δ%»
   - Цветовая индикация: рост расходов — красный, снижение — зелёный
4. **Мини-график** — bar chart с двумя рядами (текущий и предыдущий период) по категориям
5. **Топ изменений:** «Больше всего выросло: Кафе +40%», «Больше всего снизилось: Транспорт -15%»
6. **Период «3 месяца»** — line chart с трендом расходов по месяцам (без режима сравнения)

### Файлы для изменения

### Acceptance Criteria

**AC-1:** Given period selector «Этот месяц» и toggle «Сравнить» включён, When страница открыта, Then отображаются данные текущего и прошлого месяца рядом

**AC-2:** Given сравнение включено, When расходы по категории выросли, Then дельта отображается красным с «+X%»

**AC-3:** Given сравнение включено, When расходы по категории снизились, Then дельта отображается зелёным с «-X%»

**AC-4:** Given period selector «3 месяца», When выбран, Then отображается line chart с тремя точками (3 последних месяца)

**AC-5:** Given toggle «Сравнить» выключен, When страница открыта, Then отображается только текущий период без сравнения

**AC-6:** Given данные только за 1 месяц (новый пользователь), When режим сравнения включён, Then показывается сообщение «Недостаточно данных для сравнения. Нужно минимум 2 месяца»

**AC-7:** Given топ изменений, When сравнение включено, Then отображаются 2 строки: «Больше всего выросло» и «Больше всего снизилось» с названием категории и %

**AC-8:** Given период «6 месяцев», When выбран, Then line chart показывает 6 точек с суммарными расходами по месяцам

### Edge Cases

- **Нет данных за предыдущий период:** показывается «—» в колонке «Предыдущий»
- **Категория есть только в одном периоде:** дельта = +100% или -100%
- **Нулевые расходы в предыдущем периоде:** дельта не вычисляется (деление на ноль), показывается «Новая»
- **Текущий месяц только начался (1–3 дня):** предупреждение «Данных за текущий месяц мало»

### Метрики успеха

- **Primary:** % пользователей, использующих режим сравнения хотя бы раз в месяц ≥ 25%
- **Guardrail:** время рендеринга таблицы сравнения < 100ms

### Явно вне скоупа

- Сравнение произвольных периодов (только предустановленные)
- Экспорт таблицы сравнения (TASK-021)
- Прогнозирование на основе тренда (Sprint 4)

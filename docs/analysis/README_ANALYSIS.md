**Цель:** Разработать персонализированный алгоритм оценки дневного бюджета на основе исторических данных пользователя.

**Результат:** Улучшенный алгоритм, который:
- ✅ Устойчив к выбросам в доходах
- ✅ Персонализирован на основе истории пользователя
- ✅ Даёт реалистичные оценки дневного бюджета
- ✅ Учитывает паттерны по дням недели

## 🚨 Проблемы исходного алгоритма

### Результаты на реальных данных (май 2026)
```
💵 Бюджет на месяц: 703,511 ₽ ❌ (аномально высокий!)
📅 Можно потратить сегодня: 41,212 ₽ ❌ (нереалистично)
📆 Можно до конца месяца: 700,603 ₽ ❌ (нереалистично)
```

### Корневые причины
1. **Использует доход текущего месяца без фильтрации**
   - Аномальный доход (703,511 ₽) искажает бюджет
   
2. **Нет защиты от выбросов**
   - Крупные разовые поступления рассматриваются как регулярные доходы
   
3. **Не учитывает исторические паттерны**
   - Бюджет не адаптируется к поведению пользователя
   
4. **Жёсткие критерии для постоянных расходов**
   - `fixed_monthly = 0` — алгоритм слишком строгий

## ✅ Улучшенный алгоритм

### Ключевые улучшения

#### 1. Фильтрация аномальных доходов (IQR метод)
```typescript
function filterOutliersIQR(values: number[], multiplier: number = 2.0): number[] {
  const q1 = percentile(values, 25);
  const q3 = percentile(values, 75);
  const iqr = q3 - q1;
  
  const lowerBound = q1 - multiplier * iqr;
  const upperBound = q3 + multiplier * iqr;
  
  return values.filter(v => v >= lowerBound && v <= upperBound);
}
```

**Результат:** Аномальные доходы (703,511 ₽) исключаются из расчёта бюджета

#### 2. Использование медианы для бюджета
```typescript
const budget = median(filteredIncomes);  // Не среднее!
```

**Результат:** Бюджет устойчив к выбросам

#### 3. Смягчённые критерии для постоянных расходов
```typescript
const varianceThreshold = 0.40;  // Было 0.20
```

**Результат:** Больше категорий распознаются как постоянные

#### 4. Корректировка на день недели
```typescript
const multipliers = {
  'Sunday': 1.3,      // Самый дорогой день
```

## 🎓 Уроки learned

### 1. Медиана > Среднее для финансовых данных
- Среднее искажается выбросами
- Медиана устойчива к аномалиям
- Используйте медиану для бюджетов

### 2. Фильтрация выбросов критически важна
- Аномальные доходы (703,511 ₽) искажают бюджет в 19x
- IQR метод — простой и эффективный
- Настройте множитель под данные пользователя

### 3. Персонализация имеет значение
- Паттерны по дням недели различаются в 3.4x
- Учёт индивидуального поведения улучшает точность
- Адаптивные алгоритмы > статические правила

### 4. Прозрачность = доверие
- Показывайте, как вычисляется бюджет
- Объясняйте множители и фильтры
- Давайте пользователю контроль

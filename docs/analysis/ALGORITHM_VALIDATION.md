- ✅ IQR фильтрация не исключила значения (нужна настройка)

### Рекомендации по настройке параметров

1. **IQR множитель:** Текущий 1.5 (стандартный)
   - Для этого пользователя: увеличить до 2.0 или 3.0
   - Причина: высокая волатильность доходов

2. **Количество месяцев для бюджета:** Текущий 5
   - Рекомендация: увеличить до 6-12 месяцев
   - Причина: больше данных = более стабильная медиана

3. **Порог дисперсии для постоянных расходов:** Текущий 0.35 (35%)
   - Рекомендация: оставить 0.35 или увеличить до 0.40
   - Причина: постоянные расходы не обнаружены (слишком строгий критерий)

## Недостатки и области для улучшения

### 1. Постоянные расходы не обнаружены
**Проблема:** `fixed_monthly = 0` для всех тестов

**Причины:**
- Слишком строгий критерий дисперсии (35%)
- Категории "Прочие операции" (73.9% расходов) не анализируются
- Недостаточно данных для некоторых категорий

**Решения:**
- Увеличить порог дисперсии до 40-50%
- Добавить анализ подкатегорий в "Прочие операции"
- Использовать более мягкие критерии (присутствие в 2 из 3 месяцев)

### 2. Бюджет может быть занижен
**Проблема:** Медиана (36,818 ₽) ниже типичных доходов пользователя

**Причины:**
- Высокая волатильность доходов
- Нерегулярные крупные поступления
- Короткий период анализа (5 месяцев)

**Решения:**
- Увеличить период анализа до 12 месяцев
- Использовать взвешенную медиану (свежие месяцы = больший вес)
- Добавить опцию "ручного бюджета" для пользователя

### 3. Нет учёта крупных разовых расходов
**Проблема:** Алгоритм не отличает регулярные расходы от разовых

**Примеры:**
- Образование: 112,500 ₽ (1 транзакция)
- Путешествия: 123,916 ₽ (4 транзакции)

**Решения:**
- Обнаруживать крупные разовые расходы (> 50,000 ₽)
- Исключать их из "постоянных расходов"
- Показывать отдельно "разовые крупные траты"

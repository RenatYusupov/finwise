## 5. Проблемы с текущим алгоритмом

### Текущий результат (май 2026)
- **Бюджет:** 703,511 ₽ (аномально высокий!)
- **Можно потратить сегодня:** 41,212 ₽
- **Можно до конца месяца:** 700,603 ₽

### Проблемы

1. **Аномальный доход искажает бюджет:** 703,511 ₽ в мае 2026 — это явно не типичный месяц
2. **Нет фильтрации выбросов:** Алгоритм использует все данные без очистки
3. **Медиана не используется для бюджета:** Используется доход текущего месяца, а не медиана исторических
4. **Постоянные расходы не обнаружены:** `fixed_monthly = 0` — алгоритм слишком строгий

---

## 6. Рекомендации по улучшению алгоритма

### 1. Фильтрация аномальных доходов
- Исключать доходы > 3 стандартных отклонений от медианы
- Или использовать winsorization (обрезать на 95-м перцентиле)

### 2. Использование медианы для бюджета
- Бюджет = медиана доходов за последние 3-6 месяцев (без аномалий)
- Или взвешенная медиана (более свежие месяцы имеют больший вес)

### 3. Улучшенное обнаружение постоянных расходов
- Снизить порог дисперсии с 20% до 30-40%
- Учитывать категории с низкой вариативностью (Телефон, Интернет)

### 4. Учёт дня недели
- Корректировать "можно сегодня" на основе паттернов дня недели
- Например, в воскресенье можно тратить больше, чем в среду

### 5. Сглаживание расходов
- Использовать экспоненциальное сглаживание для прогноза
- Учитывать сезонность (месяцы с высокими расходами)

## 7. Предложенный алгоритм

```python
def compute_safe_to_spend_improved(df, current_date=None):
    """
    Улучшенный алгоритм вычисления "можно потратить сегодня"
    """
    if current_date is None:
        current_date = datetime.now()
    
    # 1. Фильтрация аномальных доходов
    monthly_incomes = get_monthly_incomes(df, months=6)
    filtered_incomes = filter_outliers(monthly_incomes, method='iqr')
    
    # 2. Бюджет = медиана отфильтрованных доходов
    budget = np.median(filtered_incomes)
    
    # 3. Уже потрачено в этом месяце
    already_spent = get_monthly_expenses(df, current_date)
    
    # 4. Постоянные расходы (смягчённые критерии)
    fixed_expenses = detect_fixed_expenses(df, months=3, variance_threshold=0.35)
    fixed_monthly = sum(fixed_expenses.values())
    
    # 5. Остаток
    remaining = max(0, budget - already_spent)
    
    # 6. Корректировка на день недели
    day_of_week = current_date.strftime('%A')
    day_multiplier = get_day_of_week_multiplier(day_of_week)  # Sunday=1.3, Wednesday=0.9
    
    # 7. Можно потратить сегодня
    days_left = get_days_left_in_month(current_date)
    safe_today = (remaining / days_left) * day_multiplier
    
    return {
        'budget': budget,
        'already_spent': already_spent,
        'fixed_monthly': fixed_monthly,
        'remaining': remaining,
        'safe_today': safe_today,
        'days_left': days_left,
        'day_of_week': day_of_week,
        'day_multiplier': day_multiplier,
    }
```
